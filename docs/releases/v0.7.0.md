Redesigned library, reader and settings interface, plus a MEGA cancellation fix.

- Folder navigation no longer rejects a metadata read because a previous cover transfer is cancelling. New transfers wait for native completion in the background; actual provider errors and a bounded timeout remain visible.
- The library has source cards, reading filters, rounded covers with file actions, a floating add button and Library/Recent/Favorites/Downloads destinations.
- The reader has black controls, direct bookmarks/brightness/direction/zoom/volume tools, an optional progress bar and space reserved for visible controls.
- Settings use five searchable cards with current values and inline reader, synchronization and update switches.
- OLED/blue is the new default. Existing explicit theme/language preferences, accounts, offline copies and progress are retained. Light/dark themes and orange/teal accents remain available. English and Spanish are included.

Validation: debug and minified release builds, 39 JVM tests, formatting and Android lint. The updated 19-group Android suite and visual checks could not run because the local emulator will not boot. Live MEGA cancellation and physical-tablet behavior remain unverified.

Use the ARM64 APK for ARM64 tablets. Install over the previous version to retain data. This release keeps the original test signing certificate; Android or Play Protect may reject installation. No protection was disabled.
