The gear menu now opens a grouped, scrollable settings panel with readable current values.

- Appearance: theme, app language and startup screen.
- Reading: page fit, manga direction and controls.
- Library and downloads: library source, sorting, refresh, comic downloads and direct MEGA cover settings.
- Cloud and progress: accounts, synchronization preferences/actions, and progress backup/restore.
- Application: GitHub updates and About.

Rows reuse the app's native navigation style and official Material icons. Section headings support accessibility navigation; the panel adapts to phone/tablet size and orientation and retains light, dark and OLED themes. Comic download and cover preferences are separated, and synchronization is no longer buried in account selection.

Existing accounts, reading state, settings keys, background cover work and update validation are preserved. Install over the previous version; use the ARM64 APK for ARM64 phones and tablets. The original signing certificate is retained.
