Reduces repeated MEGA folder errors when browsing a saved library.

- If a folder is missing from the loaded SDK tree, reload the authenticated tree once before reporting that it is unavailable. Valid folders reuse the existing tree; a genuinely missing folder still fails.
- Keep the MEGA session loaded while the library is visible. Cover preparation and sync cleanup no longer disconnect an active browser, and canceled cover work no longer performs duplicate session teardown.
- Show automatic refresh failures as a localized, tappable status inside the library, preserving cached entries and reading progress. Explicit refreshes, downloads and account actions retain their error dialogs.

Validation: 51 passing JVM tests, including nine MEGA lifecycle tests with SDK protocol doubles and five regressions reproduced before the fix; 24 Android framework layout renders; debug, Android-test and minified release builds; lint and formatting. Live MEGA account behavior, physical-device operation and the instrumented Android suite remain unverified.

Install over the existing version to keep accounts, offline files, preferences and progress. The ARM64 APK is intended for ARM64 phones and tablets. The original test signing certificate is retained; Android or Play Protect may reject installation.
