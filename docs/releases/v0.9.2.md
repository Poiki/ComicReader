Keeps unfinished comics visible in the wide and tall reading widgets.

- The former Next issue widget is now Reading & next (En curso y siguientes in Spanish). It shows unfinished comics first, with the last opened first, then fills available slots with upcoming issues from their original series and folders. Existing widget instances keep working.
- Background cover updates no longer postpone a pending widget refresh indefinitely. Updates remain event-driven and use cached metadata and covers, with no polling or cloud downloads from the widget.
- Both the 4 × 2 and 4 × 4 layouts are checked with two readings from separate cached MEGA folders, including one whose local copy was removed. Continue reading and Reading shelf retain the same unfinished-first ordering.

Validation: the queue-selection test reproduced the previous omission of unfinished comics, and another regression reproduced a cover event delaying the second reading's automatic appearance. Host framework tests cover API 28 and 34, foreground cancellation, subsequent refreshes, completion removal, source-specific next issues, responsive layout bounds and bitmap/IPC budgets. Physical launcher behavior and live cloud-account transfers remain unverified.

Standard and Google-free APKs retain the original signing certificate. Install over the existing app to retain local data; Google-free upstream APKs are not packages published by the official F-Droid repository.
