Replaces the RAR backend, adds a Google-free distribution variant and optional Ko-fi support.

- CBR/RAR reading now uses the project's embedded read-only JNI adapter with libarchive 3.8.11. Junrar and its logging dependency are removed. Forward decoder state, seekable non-solid reads and a bounded repeated-page cache reduce repeated work. Source archives are never modified or extracted to filesystem destinations.
- Resource guards retain entry/page/total limits and reject encrypted, split and multi-volume archives. The native source patch closes a stored-RAR final-checksum gap reproduced by the existing corruption test. Compressed RAR4 and solid RAR5 are covered by host fixtures.
- `-Pdistribution=fdroid` excludes Google Play Services, Google Drive authorization, the APK updater and installer permission/provider. Local reading, MEGA and WebDAV remain available. About and listing text explain the difference in English and Spanish. Official F-Droid inclusion and a validated packaging recipe remain pending.
- Optional Ko-fi support appears in settings and the README using the app's dark/cyan styling. The app opens a browser only after an explicit tap; no payment SDK, embedded script or donation requirement is added.

Validation: 92 passing standard JVM tests and 95 F-Droid-variant tests; debug, instrumentation and minified release builds; lint; native RAR4/RAR5/CRC/size/order/cancellation/source-immutability checks; static REA package/class inspection and dependency verification for the Google-free APK. Physical devices, live cloud accounts, battery/performance measurements on Android and official store builds remain unverified. Host timings are not Android performance evidence.

Standard APK names and the original signing certificate are retained for updates. Google-free upstream APKs are named `ComicReader-fdroid-<abi>.apk`; they are not packages published by the official F-Droid repository. Install over the existing app to retain local data; switching to a future differently signed store package will require a separate migration plan.
