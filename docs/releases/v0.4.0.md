Android CBZ/ZIP and PDF reader with a persistent MEGA library, reading filters and light, dark and OLED black themes.

This release adds GitHub Releases updates: startup checks at most once a day, manual checks, compatible APK downloads, and SHA-256, signing-certificate, package and version validation. Android confirms installation. No GitHub account or token is required.

- **ARM64 phones and tablets:** `ComicReader-arm64-v8a.apk`.
- **x86_64 devices and emulators:** `ComicReader-x86_64.apk`.
- **Both architectures:** `ComicReader-universal.apk`.

Install over the previous version to retain your library, accounts and progress. Upgrading from 0.3 requires installing this APK once; subsequent releases can be found in the app's update settings.

The official MEGA SDK is included for direct login. Google Drive requires your own package/certificate OAuth registration. CBR, RAR and 7z are not supported in this version.

The original test signing certificate is preserved; this is not a Play Store production identity. Checksums are in `SHA256SUMS`. No physical tablet performance or battery measurements were made.

The update test downloaded and validated this release and opened Android's installer. Play Protect rejected the final emulator installation with `INSTALL_FAILED_VERIFICATION_FAILURE`. Protections were not disabled; complete installation remains unverified in that environment.
