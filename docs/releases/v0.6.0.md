Fixes the first MEGA comic download failing with "Cannot save the comic" when no local file had been imported. The shared import path now creates the library directory before moving a cloud download. Existing comics, accounts and reading state are preserved.

- MEGA covers load for visible comics and remain cached between app launches. Native thumbnails are used when available; otherwise a temporary comic download generates the cover and is removed. Default: unmetered networks, with settings for mobile data or downloaded comics only. Transfers use MEGA quota.
- Background cover work yields to user downloads, stops on pause or a disallowed network, and respects low battery/battery saver. Memory is limited to 8 MiB, disk thumbnails to 32 MiB/2,000 files, and the work queue to 32 entries.
- Direct MEGA, Drive and WebDAV comic downloads default to unmetered networks. A separate switch under **Downloads and covers** allows mobile data; connection changes interrupt a download when its network becomes disallowed.
- English and Spanish UI follow the device language, with an in-app language picker and Android 13+ per-app language support.
- Official Google Material Icons replace custom interface icons; their Apache-2.0 license is included.
- GitHub Releases are checked on each foreground open instead of once a day. Android still confirms APK installation.
- The README and maintained guides are consolidated in English. Java formatting and shared resources are consistent; historical APK research remains in Git history.

Use `ComicReader-arm64-v8a.apk` for OnePlus Pad 2. Install over the previous version, keeping the existing test signing certificate. A previous emulator update was rejected by Play Protect after download/validation; installation approval remains Android's decision. No physical-tablet or battery benchmark is claimed.
