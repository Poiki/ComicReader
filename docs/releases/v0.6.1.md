Cover preparation now starts when the app opens and runs independently of the library screen, including when startup opens connections or the last comic.

- Prepare local covers and missing covers under the saved MEGA root, including subfolders, without scrolling to each comic.
- Continue through a one-shot Android background job while reading or outside the library screen. Visible covers update as cached images arrive.
- Preserve Wi-Fi/mobile settings, decoder limits, cached images and native cancellation/file ownership. Explicit downloads and sync take priority.
- Share application-owned cover data so concurrent requests generate a cover once. A background budget reserves cache space for interactive reading and avoids repeatedly downloading evicted covers in large libraries.

Android can postpone or stop work for network, battery, storage or scheduling limits. Supported versions request expedited startup, with regular constrained work when quota rejects it. No permanent service, notification permission or new runtime dependency is added.

Install over the previous version to retain accounts and reading progress. Use `ComicReader-arm64-v8a.apk` for OnePlus Pad 2. The original test certificate is preserved; Android/Play Protect controls installation approval.
